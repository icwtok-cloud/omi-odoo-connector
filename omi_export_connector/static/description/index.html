Validate Data Before Importing Into Odoo

Catch import errors before they happen — free validation report included.

1. Export

Pick a module (Contacts, CRM, Sales, Invoicing, Inventory, Products, Accounting or Purchase) and export it in one click, already formatted for your exact Odoo version.

2. Validate for free

Open OMI and upload the file. See every row with a problem, why, and how to fix it — no account or payment required to see the report.

3. Fix & import

Correct the issues, download the clean file, and import into Odoo with confidence — no more silent rejections.

Supports Odoo 14.0 through 19.0

Includes end-of-life versions (14.0-16.0), which is exactly where most migration urgency lives — Odoo surcharges databases still running unsupported versions.

Requires an external service

This module exports your data and opens OMI, an independent, external data-validation service, in your browser. OMI's validation engine is 100% deterministic (no AI) and checks your file against the real field definitions and relation values of your Odoo version and module. A free tier is available; no account is required to install or use the export wizard itself.
